# Compatibilidade e validação pendente

O aplicativo usa Windows Forms e tem como alvo .NET Framework 4.8 com arquitetura x86. A documentação oficial da Microsoft exige Windows 7 SP1 para .NET Framework 4.8 e lista requisitos de atualização do Windows 7, incluindo suporte à assinatura SHA-2 e servicing stack. O pacote offline e os detalhes atuais devem ser conferidos na página oficial de requisitos do sistema antes da instalação.

Referências oficiais identificadas para consulta pelo responsável técnico:

- Microsoft Learn, requisitos de sistema do .NET Framework: https://learn.microsoft.com/dotnet/framework/get-started/system-requirements
- Microsoft Learn, instalação do .NET Framework 4.8: https://learn.microsoft.com/dotnet/framework/install/guide-for-developers

Não foram feitas requisições de rede de pesquisa nesta implementação. As fontes acima são referências para requisitos técnicos e não foram usadas para validar os textos educativos. Compatibilidade real com Windows 7 SP1 e Windows 10, execução offline, escalas, memória e tempos de inicialização ainda não foram medidos.
