# IT Digitação 3.0 — Kit de reconstrução
1. Extraia o ZIP dentro do repositório existente, sem substituir código atual.
2. Abra `prototipo/index.html` em um navegador moderno para explorar as sete telas. Todos os recursos são locais. É uma referência visual, não um aplicativo de produção. O cronômetro é ilustrativo, os 30 títulos são exemplos, o texto é único, métricas são simplificadas, configurações são temporárias e som não implementado. O guia ABNT2 é simplificado.
3. Envie ao Codex o arquivo `PROMPT-CODEX.md` e a pasta completa. Comece pela auditoria e pela tela inicial; aprove a captura real antes de seguir.
4. `referencias/`: mockups originais recuperados. `defeitos/`: seis capturas da versão 2.0. `assets/`: logo original, quatro poses do mascote, ícones existentes e dez recortes ilustrativos provisórios (apenas arte, não controles). `ESPECIFICACAO-ANTERIOR.md`: requisitos anteriores preservados.
5. O protótipo não substitui o motor C# nem o executável. Windows 7 e 10 devem ser testados no produto real. Não há garantia de execução perfeita pelo Codex.

Validação deste kit: JavaScript passou em `node --check`. A execução visual automatizada foi bloqueada pela política do navegador do ambiente, tanto para arquivo local quanto para URL simulada. Assim, as sete telas ainda precisam ser abertas e conferidas no navegador do responsável. Nenhuma captura de execução foi fabricada. Os recursos gráficos reaproveitados precisam de inspeção visual final, especialmente transparência do mascote e recortes das categorias.
